 #  Python Data Visualization Project

This repository contains various Python notebooks focused on data analysis and visualization using libraries like **Matplotlib**, **Seaborn**, and **Pandas**.

##  Overview
In this project, I explore datasets (such as the Iris dataset) to extract insights through different types of charts, including:
* Scatter Plots for feature correlation.
* Data distribution analysis.
* Basic data cleaning and preparation.

##  Technologies Used
* **Language:** Python 3.x
* **Libraries:** Matplotlib, NumPy, Pandas.
* **Tools:** Jupyter Notebook, VS Code.

##  Project Structure
* `DV.ipynb`: Main notebook for data visualization and scatter plots.
* : Exercises on Python functions and logic.
